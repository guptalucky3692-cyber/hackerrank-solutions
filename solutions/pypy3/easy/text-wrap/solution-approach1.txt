# Insight     The implementation leverages the built-in textwrap module to efficiently partition the input string into segments of the specified maximum width.
# Interview   Before: "I would manually iterate through the string and insert newline characters at every max_width interval." After: "Using textwrap.fill provides an O(N) solution that handles word boundaries and formatting constraints automatically, which is more robust than manual slicing for this O(N) space requirement."
# Pitfalls    (1) Assuming the input string contains no existing newline characters, which might be incorrectly processed by manual iteration logic.
# ──────────────────────────────────────────────────



def wrap(string, max_width):
    return (textwrap.fill(string, max_width))
