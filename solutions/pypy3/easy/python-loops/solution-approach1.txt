# Technique   range-based-iteration

# Insight     The implementation iterates through the range of non-negative integers strictly less than n, calculating and printing the square of each index.
# Interview   Before: "I would use a while loop to track the index and square it." After: "Using a range-based for loop is more idiomatic in Python, providing O(n) time complexity while handling the n constraint efficiently."
# Pitfalls    (1) Using range(n + 1) instead of range(n) would include the square of n, violating the i < n constraint.  (2) Failing to handle the input as an integer, which would cause a TypeError during the exponentiation operation.
# ──────────────────────────────────────────────────

if __name__ == '__main__':
    n = int(input())
    for i in range(0,n):
        print(i**2)
